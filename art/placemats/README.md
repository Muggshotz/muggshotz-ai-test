# Premade placemats

Bud's placemat designs, at the quilted placemat's print shape (2925 x 2025).
Each design: `print/<key>.jpg` (printed) and `show/<key>.jpg` (on the page),
made by `python3 tools/premade-fit.py placemats <key> <artist's file>`, then
one line in PREMADE_CATEGORIES.placemats.items in needles-studio.html.
Empty until the first design arrives; the category stays hidden till then.
