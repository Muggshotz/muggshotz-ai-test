The Portal

Type any product idea below and this pulls real blueprint data straight from Printify's catalog — name, estimated base cost, available print providers, and a real product photo where Printify has one — combined with anything you've uploaded from Prodigi's CSV exports. Click "Add to catalog" on anything worth pursuing, and it collects into a running list you can export at the bottom.

Connection status

The Portal now talks to Printify through a small server-side relay (api/printify-proxy.js) rather than calling Printify directly from your browser — Printify blocks direct browser requests for security reasons, so this relay was added to work around that. It uses the Printify API token already stored in your Vercel project's environment variables. Nothing to paste in here anymore.

Upload Prodigi catalog (CSV)

Prodigi doesn't offer live search, so download a category CSV from their site and upload it here. It gets parsed and stored in this browser only (localStorage) — re-uploading a CSV for a category you've already loaded replaces just that category, so it's safe to re-upload after Prodigi updates their export.
