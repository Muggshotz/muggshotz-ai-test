3. Isolated result

This is the customer's real face -- it never gets recolored by anything on this page. This is the one true, known skin tone in the whole composite.

Face/hair boundary

Everything above the real jaw contour (traced from this exact face) is always kept -- that's unambiguously face. Below it, only pixels that genuinely match this person's real hair color count as hair (so it can hang past the chin without skin below it getting kept too); everything else below the jaw -- neck, shoulders, chest -- gets cut regardless of connectivity.
Raise this if real hair (in shadow or a stray strand) is getting cut off; lower it if a sliver of skin is being kept because it happened to be a similar tone to the hair.

The template's arms/legs/neck are simulated by an artist who never saw the real customer -- so THIS is what needs to shift, not the face. Starting point is auto-detected from the face itself, not a manual guess.
