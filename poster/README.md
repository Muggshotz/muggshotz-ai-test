# The Witness Problem

> Firsthand experience is the strongest evidence you will ever have,
> and the weakest evidence you can ever share.

## Files

- `firsthand-experience.svg` — the poster. Vector, 2:3 ratio, scales to any size.
- `index.html` — screen preview.
- `print.html` — full-bleed 24 × 36 in page. Open it and print.

## Printing

Open `print.html` in your browser and print to PDF, then send that file to the
print shop. Generating the PDF on your own machine matters: the poster is set in
Georgia, and printing it yourself embeds the real Georgia outlines in the PDF. A
machine without Georgia silently substitutes a different serif.

The layout survives substitution either way — every line is centre-anchored, so
it re-centres in whatever face is available — but Georgia is the intended look.

For a size other than 24 × 36, change the two `24in` / `36in` values in
`print.html`. Keep the 2:3 ratio (16×24, 20×30, 24×36) or the border insets
will crop.

## Design note

`STRONGEST` is set in solid ink. `WEAKEST` is outline only, so the weaker word
carries less ink on the page.

There is a short accent rule in the lower third. It anchors the composition, and
a name or date can go underneath it if you want one.
