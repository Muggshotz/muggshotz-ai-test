How this works

  1. Open the studio with a fresh ?v= number each session (e.g. ?v=42, then ?v=43…). A bare URL can serve yesterday’s build from your cache.
  2. Do a row. If the studio behaves as the row describes, tick the box. Ticks save by themselves, in this browser — there is no save button and nothing to download. They’ll be here when you come back.
  3. If a row does something wrong, tell Claude the row number and what you saw. A screenshot helps. That number is all Claude needs to find the exact path.
  4. To get back to this page later: bookmark it, or press ctrl+] in the Claude Code terminal, or type /artifacts.
